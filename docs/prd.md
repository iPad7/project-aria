# PRD — aria (LLM, Love Language Model)

> 초안. 제품 결정 미정은 `TODO(제품)`. 아키텍처 상세는 `docs/architecture.md`, 릴리스 단계는 `docs/mvp-plan.md`.

## 1. 개요

AI 페르소나가 **실시간 스트리밍으로 연애상담**을 진행하는 플랫폼. 시청자 채팅에 페르소나별 성격·말투로 반응하고, 응답을 TTS 음성 + 아바타 영상 + 자막으로 라이브 송출한다. (SKN13 파이널 레거시를 구조 재설계로 재구축)

## 2. 배경 / 문제

- 심리상담형 = 전문성↑ / 접근성·비용 부담. 소비형 콘텐츠 = 접근성↑ / 일방향·맞춤피드백 부족.
- **aria = 맞춤 대화의 전문성 + 스트리밍의 즉시성·참여성**을 결합한다.
- 레거시는 구조 붕괴(God object·인메모리·추론 결합)로 확장·운영이 불가 → 재구축.

## 3. 타겟 사용자

- 주: 연애 고민을 **가볍고 익명으로** 나누고 싶은 시청자(MZ).

## 5. 기능 요구사항 (FR)

### 5.1 채팅 (FR-CHAT)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-CHAT-1 | 시청자는 WebSocket으로 실시간 채팅을 전송한다 | P0 |
| FR-CHAT-2 | 채팅은 같은 방 전 시청자에게 브로드캐스트된다 | P0 |
| FR-CHAT-3 | 채팅은 가이드라인 필터(욕설 등)로 차단될 수 있다 | P0 |
| FR-CHAT-4 | 채팅 메시지는 방별 영구 로그로 저장된다 | P1 |
| FR-CHAT-5 | 입장/퇴장 등 시스템 메시지를 표시한다 | P1 |

### 5.2 페르소나·생성 (FR-GEN)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-GEN-1 | 시스템은 유입 채팅을 토픽으로 군집화하고 활성 토픽을 추적한다 | P0 |
| FR-GEN-2 | 활성 토픽에서 반응할 베스트 댓글을 선별한다 | P0 |
| FR-GEN-3 | 선별 댓글에 페르소나(가치관·말투·도덕·성격기질)를 반영해 응답을 생성한다 | P0 |
| FR-GEN-4 | 생성은 페르소나별 sLLM으로 하고, 불가 시 OpenAI로 폴백한다 | P0 |
| FR-GEN-5 | 생성 응답의 감정을 분류해 미디어에 반영한다 | P1 |
| FR-GEN-6 | 후원(슈퍼챗)은 우선 처리되어 감사 응답을 생성한다 | P1 |

### 5.3 미디어 송출 (FR-MEDIA)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-MEDIA-1 | 응답 텍스트를 TTS 음성으로 합성한다 | P0 |
| FR-MEDIA-2 | 감정에 맞는 아바타 클립과 자막을 선택/생성한다 | P0 |
| FR-MEDIA-3 | 음성+영상+자막을 HLS 세그먼트로 합성해 CDN으로 송출한다 | P0 |
| FR-MEDIA-4 | 응답 사이 공백에는 idle 아바타 루프를 재생한다 | P0 |
| FR-MEDIA-5 | 응답은 seq 순서로 재생되어 시청자 간 일관성을 유지한다 | P0 |

### 5.4 자동 진행 (FR-IDLE)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-IDLE-1 | 무채팅이 지속되면 자율 발화(혼잣말·개방형 질문)를 생성한다 | P0 |
| FR-IDLE-2 | 대기 중인 시청자 사연을 읽고 공감/조언한다 | P1 |
| FR-IDLE-3 | 방송 시작 시 사연 읽기로 오프닝을 진행할 수 있다 | P2 |

### 5.5 결제·지갑 (FR-PAY)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-PAY-1 | 시청자는 토스로 크레딧을 구매한다 | P1 |
| FR-PAY-2 | 결제 확정은 멱등 webhook으로 처리되고 크레딧이 지급된다 | P1 |
| FR-PAY-3 | 시청자는 크레딧으로 후원(슈퍼챗)한다 | P1 |
| FR-PAY-4 | 환불은 보상 처리되며, 이미 사용된 크레딧은 정책에 따른다 | P2 |

### 5.6 인증·관리 (FR-AUTH)

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-AUTH-1 | 사용자는 회원가입/로그인(JWT)한다 | P1 |
| FR-AUTH-2 | 미인증 사용자의 스트림 접속은 거부된다 | P1 |
| FR-AUTH-3 | 관리자는 방송·페르소나·TTS 설정을 관리한다 | P1 |

### 5.7 방송국·커뮤니티 (FR-STATION)

스트리머(페르소나)별 팬덤 채널 페이지.

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-STATION-1 | 시청자는 페르소나별 방송국 페이지에서 프로필·좋아요 수를 본다 | P1 |
| FR-STATION-2 | 사용자는 사연 게시판에 글을 작성한다 (제목·내용·익명·관계단계·닉네임) | P1 |
| FR-STATION-3 | 사용자는 사연 게시판 목록을 열람한다 | P1 |
| FR-STATION-4 | 제출된 사연은 라이브 idle에서 AI가 읽을 후보가 된다 (→ FR-IDLE-2) | P1 |
| FR-STATION-5 | 사용자는 스트리머에 좋아요(토글)를 누른다 | P2 |
| FR-STATION-6 | 방송국은 후원 랭킹(열혈순위)을 표시한다 | P2 |
